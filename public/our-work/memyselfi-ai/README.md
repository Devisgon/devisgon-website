# MeMyselfI.ai portfolio assets

The supplied brand assets are included in this folder:

- `logo.png` — complete logo with wordmark, used where the full brand name is needed.
- `icon-symbol.png` — compact brand symbol used on project cards and the case-study hero.
- `hero.webp` — optimized version of the supplied hero image, used in the homepage card, work listing card and project detail hero.

To add more project screenshots or UI/UX and graphic-design exports, upload them here and set the corresponding `src` values in `src/data/featured-work.ts`. The project live URL remains empty until supplied.
