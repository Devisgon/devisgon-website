# MeMyselfI.ai portfolio assets

Upload approved public portfolio images into this folder using these filenames:

- `logo.png`
- `website.png`
- `web-app.png`
- `mobile-app.png`
- `design.png`

Then set `logoSrc` and the corresponding image `src` values in `src/data/featured-work.ts` to `/our-work/memyselfi-ai/<filename>`. Leave `liveUrl` empty until the public project link is ready. The page displays clearly marked upload slots until assets and links are supplied.
